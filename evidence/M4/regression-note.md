# M3 regression during the M4 increment

The fresh M3 boot suite passed all 14 boot/error/SMP cases. The first visual/idle run observed all four CPUs halted but failed its separate two-second QEMU host-CPU sampling threshold (15% of one host CPU). That run did not produce a passing visual report; the overall verifier correctly stopped with failure. The unchanged-source visual rerun passed, observing all four CPUs halted and 0.0 host CPU seconds during its two-second sample. The cause of the earlier sample excursion is unresolved; a passing rerun does not explain it. Repository and M0 gates were then run separately and the acceptance summary collected those individual reports. This host-process sampling result is not a physical OS CPU benchmark or proof of a kernel scheduler failure.

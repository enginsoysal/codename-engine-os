# Engine OS 0.9.1 — corrected VMware starter

This is a **VMware packaging correction**, not a new kernel or ISO. The original M9 ZIP enabled e1000e without PCIe root ports. The owner's VMware log reports `No PCIe slot available for Ethernet0`, failed e1000e registration and a VMware access violation, surfaced as VMDB error -14. The earlier starter lifecycle disabled Ethernet and therefore missed the shipped-device failure. That test gap is explicitly corrected here.

The corrected configuration adds the PCI bridge and a PCIe root port with eight functions. It keeps NAT Ethernet, sound, SATA and the original display configuration enabled. The regression must use the extracted shipped configuration, adding only the owned test's authenticated loopback display and COM1 observations. It must not disable a shipped device to obtain a passing result.

Qualification scope is **M91-STARTER-v1**. [Correction evidence](../../evidence/M9.1/acceptance-results.json), [read-only incident diagnosis](../../evidence/M9.1/incident.json). The real guest regression covers installation, retained-ISO restart, original Windows-app lifecycle, persisted folder creation and two independent disk-only boots with the same VM/NVRAM and enabled devices.

IDE installation, unqualified SCSI controllers, physical hardware, automatic display-mode changes and 3D remain unsupported or separate work. The graphics/kernel scope remains the bounded [M9 delivery](m9-v0.9.0.md). No claim is made that every custom VM is fixed by this package.

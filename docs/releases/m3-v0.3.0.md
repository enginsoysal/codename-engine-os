# M3 v0.3.0 — native scheduling, VM and SMP

M3 is complete within the [documented native VM scope](../milestones/m3.md), backed by [fresh evidence](../../evidence/M3/README.md). This supersedes the preemption-only alpha while retaining its historical tag/assets.

## Test in VMware

Download `EngineOS-M3.iso`, verify `M3-SHA256SUMS.txt`, fully power off the VM and replace its CD/DVD image. Select 64-bit UEFI, Secure Boot disabled, two vCPUs and 128 MiB RAM, then boot the EFI optical drive. The screen shows `M3 KERNEL ONLINE`, thread/wait/VM/SMP results, active CPUs and managed RAM totals. Firmware must expose supported ACPI MADT/xAPIC/64-bit HPET and make the 0x8000 startup page available. Automated qualification uses QEMU/OVMF, plus [VMware Workstation 26.0.1 serial/runtime tests](../../evidence/M3/vmware/README.md) at 1/2/4 CPUs and 128 MiB. This is limited to the recorded profiles; VMware framebuffer capture is not claimed.

No host disk is required. The USB image is for a disposable VM/device image workflow, not an implicit host-disk write. This release has no installer, desktop, keyboard interaction or existing Windows application support. OS installation remains M5 and desktop M6.

## Delivered and checked

- Real preemptible threads, process-shared data/rights-checked handles, independent stack/TLS and x87/SSE/MXCSR CPU state.
- Atomic manual/auto events, blocking mailbox waits, sleep, monotonic deadlines, join, cancellation and orderly process teardown.
- Anonymous reserve/commit/decommit, transactional no-memory rollback, shared/COW snapshot backing, CPU and checked-copy COW, zero reuse, bounded pressure/OOM containment and protected reserve accounting.
- 1/2/4 active CPUs with native CPL3 execution on every active CPU, per-CPU entry/IST/TSS/GDT, APIC timers, locked allocation and acknowledged TLB replacement/unmap.
- Fourteen boot/runtime/error cases, actual four-CPU halt/idle/framebuffer/debugger checks, English repository gates and original M0/M2 regressions. Reports include exact workload/resource counts and bounded dispatch TSC samples.

The runtime uses fixed process affinity and serialized kernel dispatch. Eight thread slots, two address spaces and sixteen anonymous VM pages per space intentionally bound this native profile. AVX/extended XSAVE, migration/hotplug, file paging/cache reclaim/swap and physical hardware remain outside qualification. No universal race-freedom, minimum-RAM, optimal-performance or Windows 95–11 application claim follows from these native tests.

Assets include normal ISO/USB images, kernel ELF/map, embedded native probe ELF and exact build/source/artifact hashes. GitHub asset hashes are checked against the tested files before reporting publication.

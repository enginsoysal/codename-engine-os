# M5.1 v0.5.1 — guided setup and distribution profiles

The default screen is now a numbered welcome menu: Try / open files, Install, Repair, Advanced, Details and distribution information. Ordinary installation and repair need no terminal command, placeholder or sector-count token. A disk-capacity review precedes writes; back cancels the plan. Progress and readable failures explain the next action. The terminal and COM1 diagnostics remain available deliberately.

[Download ISO](https://github.com/enginsoysal/engacer-os/releases/download/m51-v0.5.1/EngineOS-M51.iso) · [Official release/checksums](https://github.com/enginsoysal/engacer-os/releases/tag/m51-v0.5.1) · [Guided installation tutorial](../handbook/install-m51.md) · [Custom distribution tutorial](../handbook/distributions.md).

Use a new disposable x86-64 VMware VM with two CPUs, 128 MiB RAM, a new SATA hard disk and Secure Boot disabled. A 20-GiB SATA VMDK is included in the owned VMware EFI/BIOS task tests. At the welcome page choose **2**, select the actual disk number, then review before choosing **1**. After completion follow the power-off/media-disconnect instructions and start the disk.

Distribution profiles genuinely change compiled branding/colour and included native data files. The Forge example has a distinct ISO/build identity, extra selected content and actual detached installed boot. Unsafe recipes, unknown packages/fields/hooks and escaping paths are rejected. Data packages are not Windows/Linux applications or a full package manager.

[Exact scope](../milestones/m5.1.md), [acceptance](../../evidence/M5.1/acceptance-results.json), [product requirements](../architecture/product-principles.md). Automated task tests do not constitute a human usability study. This remains a keyboard text wizard, not a graphical desktop. The unchanged limits include a 16-MiB native data partition/48-KiB files, unallocated remaining capacity, SATA/512-byte install targets, unsigned media and same-build boot repair. No general upgrade/rollback, physical/factory-trust qualification, desktop/network or Windows 95–11 execution is claimed.

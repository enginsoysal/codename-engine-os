## What this release delivers

A real installed desktop after the native graphical installer: windows, launcher/taskbar, Files, Text Editor, Settings, optional Calculator, Downloads, System details and an optional Advanced Terminal window. Editor and Calculator execute original separately installed ELF code in private CPL3 address spaces. Useful document tasks, clipboard, persistent appearance, contained app faults and real executable removal/reinstall are qualified separately from rendering.

The original network stack supports named Intel 8254x/82574 virtual profiles, DHCP/ARP/DNS, bounded TCP and certificate/UTC-checked TLS 1.2 HTTPS downloads. The volume stages 4 KiB while downloading; interrupted/cancelled transfers do not publish partial files. A real public 7-Zip installer is downloaded and checked as data only. It is not executed.

## Qualified scope and limits

M7-VM-v1 covers named QEMU BIOS/UEFI ISO/USB installation and detached desktop profiles, plus VMware Workstation 26.0.1 build 25688693 BIOS/UEFI, two vCPUs, 128 MiB, 20-GiB SATA/512-byte disk, e1000e MSI/NAT and Secure Boot off. QEMU resource tasks cover 64 MiB/one CPU and 128 MiB/two or four CPUs. Network security requires RDRAND and correct UTC. Physical hardware, universal NIC/storage/GPU support and factory Secure Boot are not qualified.

Eight desktop windows, 8,191-byte editor text, 255-byte paths, 63-byte path components and 1,024 volume entries are explicit bounds. Files use contiguous copy-on-write workspace. Downloads permit one active transfer, four HTTPS redirects and at most 64 MiB per body. Saved names are unique `DownloadN.bin`. Rendering uses the CPU framebuffer, without hardware GPU acceleration or a fullscreen buffer per window. ASCII text has no Unicode input, international layout, accessibility screen reader or audio stack yet.

Resource tasks observe 159,744–258,048 managed baseline bytes, 471,040 whole-boot peak bytes, a 1,743,488-byte installed kernel span and a 4,096,000-byte QEMU framebuffer. A second Editor adds 40,960 private bytes; the checked larger download retains the same 249,856 managed bytes throughout. Idle CPUs halt with zero idle repaints. The managed allocator counters exclude the static kernel, firmware/boot reservations and framebuffer. Resource reports give each separately; configured VM RAM is not kernel consumption. The compositor, Files, Settings, Terminal and network are trusted supervisor services. Only the shipped event-worker apps have the current narrow CPL3 boundary. This is not a general application scheduler or third-party app sandbox.

TLS 1.2 uses unchanged MIT BearSSL 0.6 and pinned MPL-2.0 Mozilla/curl trust data. TLS 1.3, revocation/OCSP/CT, browser-equivalent external root constraints and authenticated network time are not implemented. The local profile has no login authentication or multi-user ACL boundary. Tests are automated user tasks, not a human usability study or production security certification.

M8 implements original MS-DOS and Windows 1.x–11 applications. M7 does not claim any original Windows executable can install or run. Historical M6 and earlier accepted media/evidence remain frozen.

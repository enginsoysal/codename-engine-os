# M5 v0.5.0 — live installation and recovery

Native text installation to a blank SATA/AHCI 512-byte-sector disk, GPT/BIOS/EFI setup, media-detached installed boot, persistent native files and same-build boot recovery. Original Engine OS kernel; MIT source. Qualification is bounded by [M5-VM-v1](../milestones/m5.md) and [exact acceptance evidence](../../evidence/M5/acceptance-results.json).

## Downloads and testing

[Official release](https://github.com/enginsoysal/engacer-os/releases/tag/m5-v0.5.0) · [ISO](https://github.com/enginsoysal/engacer-os/releases/download/m5-v0.5.0/EngineOS-M5.iso) · [documentation website](https://engaceros.brixcanvas.com).

Read the [VMware installation tutorial](../handbook/install.md) before confirming a target. Use a new x86-64 VM, two CPUs, 128 MiB RAM, a new SATA disk of at least 256 MiB, and Secure Boot disabled. Verify the downloaded ISO against `M5-SHA256SUMS.txt`. Do not use a physical/raw host disk.

## Expected behavior

The ISO displays **M5 LIVE / INSTALL / RECOVERY**. `plan N` inspects the target and prints its exact confirmation. `install N ERASE-SECTORS` copies/verifies the system. After success, power off VMware and disconnect the ISO; the disk boots the installed native kernel. Files written in installed mode persist. Live file changes are temporary and are not copied by installation.

## Explicit limits

- 64-MiB ESP and 16-MiB native ext2 data partition; remaining capacity unallocated. Maximum file size 48 KiB; not ready for application packages.
- Live overlay capped at 512 KiB of modified pages, allocated on demand. Configured guest RAM is not kernel consumption; see evidence for separate resource values.
- SATA/512-byte install targets only. Other existing discovery transports do not acquire installation support. The installer refuses nonblank reserved boot metadata rather than offering a force wipe.
- Public unsigned BIOS/UEFI media; no factory Secure Boot trust or physical hardware qualification.
- Same-build boot repair; no arbitrary upgrade/downgrade, automatic rollback, dual boot or atomic power-cut guarantee. Preserve user data separately.
- No desktop, network downloads, Windows application execution, Linux/macOS ABI or ARM support yet. Windows 95–11 remains the long-term compatibility requirement.

Earlier M4.5 and earlier tags/assets remain historical and immutable. This release changes installability within its named VM profile, not universal hardware or app support.

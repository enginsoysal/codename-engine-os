it, open it in Files and use Play/Pause/Resume. Native capture independently
checks actual HDA output and the complete original PCM waveform.

## Resource ownership and limits

Installed kernel physical span is 2,337,808 bytes, including its fixed broker
and font data. The pinned Inter coverage atlas is 220,492 bytes within that
span. Managed allocator pages are measured separately; framebuffer and retained
firmware/boot resources are separate again. The visible 4K framebuffer alone
is 33,177,600 bytes. Do not describe allocator figures as total OS RAM.

CPL3 code is loaded on demand, shared between same-app windows and released
on last close. ZIP decoder scratch exists only during extraction. PCM output
uses 86,016 bytes on the tested HDA path, bounded by 98,304 bytes; verified Stop
releases it. Fixed broker frontends do not create idle/no-op processes, but
their trusted code remains part of the protected static kernel. Idle CPUs halt;
the time service wakes once per second and active audio uses completion IRQs.

Browser supports basic static HTML/text and checked HTTPS, without JavaScript,
CSS layout, forms, cookies or embedded images. Media is 16-bit PCM WAV through
a supported analog HDA/MSI route; images are uncompressed BMP; archives are
Stored/Deflate ZIP extraction. Modern codecs, Calendar reminders/accounts,
advanced editor features and additional desktop integrations remain follow-ups.
Captured audio qualification uses QEMU HDA; VMware audio output has not been
independently recorded. Physical hardware, ARM/Raspberry Pi, factory Secure

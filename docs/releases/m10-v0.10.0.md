# Engacer OS 0.10.0 — M10 hardware phases 1 and 2

Status: **development candidate; acceptance and publication pending**.

This delivery introduces bounded hardware capability/status reporting in
Settings → Devices, saved US QWERTY/Dvorak layouts, supported wheel input and
native FAT32 removable-media file copies with flush, safe removal and reconnect.
The product is now named Engacer OS. Historical Engine OS tags, evidence and
download identities remain unchanged. The canonical repository is now
[enginsoysal/engacer-os](https://github.com/enginsoysal/engacer-os), and the
website is [engaceros.brixcanvas.com](https://engaceros.brixcanvas.com).

The intended qualification is **M10-DEVICES-VM-v1**. It requires the exact ISO
and VMware ZIP hashes, native installation/independent startup, original Windows
console/MSI regression, ordinary/4K presentation and input/USB failure tests.
Building an ISO or passing a host filesystem test does not close those gates.

USB writes require a clean mirrored FAT32 BOT device with 512-byte sectors and
working cache flush. Copies create a new file and do not overwrite destinations.
The bounded writer has no directory growth, exFAT/NTFS support or power-loss
atomicity guarantee. Failure may require offline FAT checking. USB OS installation
and formatting are separately refused. International IMEs, arbitrary HID formats,
multiple displays, physical/ARM qualification, broader network/audio, vendor GPU
3D and Windows Steam gaming remain later work.

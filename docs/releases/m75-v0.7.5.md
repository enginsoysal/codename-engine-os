## What changed

The native installer has a bordered disk list with large whole-row selection, visible radio state, capacity and empty/existing/unsupported guidance. Next is unavailable until a usable choice is made. Empty disks are prepared automatically; erasing existing files requires a clear choice and separate final consent. Partition rows in Disk tools are fully clickable too.

The fixed window remains visible between steps. Keyboard focus updates only its borders, account typing only the input region and progress only the changing stage/bar. There is no added full-resolution framebuffer or browser dependency. Each ordinary page was reviewed for clarity, convenience, user friendliness, appearance and readability using novice scenarios. This is agent review, not a study involving children or older adults.

Restart is the primary completion action. Matching M7.5 ISO media may remain attached: the actual installed loader/bootstrap runs, rather than reopening the live kernel. Separate unforced starts with media removed verify independent disk boot. The immediate desktop remains a clearly secondary shortcut.

## Validation and limits

Actual native journeys cover 3840×2160, a confirmed 64-MiB guest, BIOS, retained-ISO restart, media-detached startup, saved account/colour/guide choices, real folder navigation and Calculator work. Missing/small disks, existing data, cancelled consent and injected SATA write errors are checked. A two-disk replacement test hashes the entire unselected equal-capacity disk to establish it is unchanged.

VMware UEFI starter and BIOS profiles install offline, restart with the ISO attached, create a persistent folder and then boot twice without CD/DVD connection using the same VM/NVRAM and no forced boot priority. Existing VM inventory remains unchanged. All 1,043 prior frozen proofs are verified unchanged.

This is not universal hardware, Raspberry Pi, factory Secure Boot or DOS/Windows application support. SATA/512-byte installation limits and whole-disk replacement remain; there is no dual boot or resize. Use the fresh starter: cross-release package migration is unqualified. The eighteen native providers and their existing bounded format capabilities remain; full modern web rendering and broader media codecs are not added.

## What you receive

An original native framebuffer wizard with seven visible steps, keyboard and USB/PS/2 mouse navigation, retained Back choices, optional guide, local name/accent, explicit whole-disk review and real verified progress. The installed disk boots without the ISO and retains preferences and files. An optional guide can be removed independently. Finish shows restart instructions; power off, disconnect the ISO and restart yourself.

A selected blank SATA/512-byte-sector disk receives GPT, BIOS and EFI boot resources, two 512-MiB system-bundle slots and the remaining aligned capacity for native data. The original copy-on-write volume streams files through 4-KiB buffers; it supports 1,024 entries and files beyond the previous 48-KiB bound. Tests write and recheck a file over 2 MiB after detached reboot.

ISO-assisted Update stages an actual different kernel build; Rollback restores the prior verified bundle; Repair restores active boot resources. Redundant activation records reject uncertain boot identity. Injected copy, format and activation errors have tested restart/recovery paths. These are verified stored bundles, not automatic bootloader A/B failover.

## VMware quick start

Create a separate x86-64 VM, two vCPUs, 128 MiB RAM, new 20-GiB SATA disk, BIOS or UEFI and Secure Boot disabled. Attach the ISO. Follow Next, select the disk, customize, review and Install. After Finish, power off, disconnect the ISO and boot the disk. Use a new disk instead of an M5/M5.1 demonstration disk; no old-format migration is implemented.

The ISO is optical media. `EngineOS-M6-usb.img` is the separate raw USB artifact. U1 is an update-test build of the same sources, not the main user download. Minimal demonstrates a separately branded installable profile with the optional guide disabled.

Qualification covers QEMU BIOS/UEFI ISO/USB, VMware BIOS/UEFI on 20-GiB SATA, independent layout/payload inspection, multiple detached boots, persistent customization, cancellation/refusal, removal, update/rollback/repair, fault injection, mouse/keyboard and advanced terminal tasks. Actual C storage checks inject 188 failed/torn write/flush positions; planner checks cover 10,005 geometry/refusal cases.

QEMU menu checks run at 64/128/256 MiB with 1/2/4 CPUs. Idle CPUs execute HLT and repeated navigation does not grow allocator usage. Managed retained memory is 139,264/172,032/237,568 bytes, with 466,944 bytes peak in this scenario. These are allocator counters, not total RAM: the kernel physical span is 1,873,893 bytes, including static storage state, and firmware/boot reservations are additional. Five deliberate allocator failures belong to the retained native regression probes. Recommended VMware configuration remains 128 MiB.

## Explicit boundaries

The installed screen is a landing/setup interface; the desktop, file manager, editor, networking and real downloads are M7. Executable packages and Calculator are not supplied by the optional data-guide mechanism. MS-DOS and Windows 1.x–11 compatibility remain M8. Local names are preferences, not login authentication/ACLs.

Target arithmetic is 2 GiB–2 TiB with 512-byte sectors; runtime tests name actual capacities and devices. Unsupported controllers, physical hardware, Secure Boot factory trust, arbitrary power loss, cross-format migration and universal flawless application support are not qualified. The volume uses contiguous extents; replacement needs free workspace. Interrupted boot replay can require the ISO. No human usability study is claimed.

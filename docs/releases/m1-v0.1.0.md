# M1 — first own-kernel VM boot

Codename: Engine OS now boots its own x86-64 kernel from a UEFI ISO. This is an early developer prerelease, not an installer or a daily-use desktop.

## Included

- Original UEFI loader, validated ELF64 kernel load and explicit ExitBootServices handoff.
- Own page tables, stack, GDT/TSS/IDT, serial diagnostics and framebuffer boot console.
- Symbolized real CPU exception diagnostics and a loopback debugger launcher.
- Normal-mode optical ISO and GPT/FAT32 USB image, plus kernel debug symbols/map.
- Source/artifact build manifest and SHA-256 checksums.

## Verified

29 M1 checks pass: exact C ELF parser tests, ISO/USB kernel boots, 128 MiB boot, stale-mapkey retry, real #UD exception, invalid bootheader/ELF rejection, persistent normal boot, framebuffer capture and GDB RSP handshake. All 51 M0 regression checks also pass. Evidence is in `evidence/M1` in the tagged source.

Test platform: pinned Windows-host QEMU pc-q35-11.1 with TCG, x64 OVMF, normally 512 MiB and two vCPUs. Physical hardware and other hypervisors are not qualified. Use UEFI without Secure Boot, not Legacy BIOS.

## Run

Download `EngineOS-M1.iso` and validate it against `SHA256SUMS.txt`. For the exact tested launcher, clone the source repository, install the documented host dependencies and run:

```powershell
python tools/vm/run.py --milestone M1
```

Place the downloaded ISO at `dist/EngineOS-M1.iso` or build it with `python tools/build/m1.py`. Use `--usb` for the downloaded USB image at `dist/EngineOS-M1-usb.img`. See [M1 instructions](https://github.com/enginsoysal/codename-engine-os/blob/main/docs/milestones/m1.md).

The normal kernel stays on its boot screen; close the VM window to stop. There is no keyboard handling, shell, installation workflow, storage driver, usermode or Windows app compatibility yet. Windows 95–11 remains the explicit future compatibility requirement, not a capability of this release. The bootstrap identity-map is temporarily broad RWX and unsuitable for untrusted apps; memory isolation is the next milestone.

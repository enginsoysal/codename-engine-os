# Engacer OS M11.4 / 0.11.4 — windows and appearance

Native qualification passed on 11 November 2026 within **M11-STAGE4-VM-v1**.
[Exact acceptance](../../evidence/M11/4/acceptance-results.json) binds 556 source
inputs, thirteen build artifacts and the separately tested VMware ZIP. GitHub
release and fresh public site/download readback are separate publication gates.

This is the M11.4 stage delivery. It adds native window commands, snapping,
keyboard window switching and per-user appearance to the accepted M11.1 input,
M11.2 Files and M11.3 Start/taskbar implementation. It does not complete the
expanded M11.5 installation journey or the full M11.6 regression matrix.

## Qualification boundaries

Sixteen native tasks, twelve exact cached/full frame comparisons and seven host
classifier groups pass. The exact VMware SATA/UEFI starter performs a real
installation, same-VM retained-ISO restart and two disk-only starts with every
shipped device enabled. QEMU ordinary/150%/actual-3840x2160 buffers, all resize
edges/corners, snap/restore, switcher/cancel, USB/PS2 shortcuts, dirty-close review,
independent saved-byte inspection and detached startup pass. Managed pages stay
constant during window/motion tasks; idle paints stay unchanged and all CPUs
halt. Extra fixed desktop BSS/data is 768 bytes above M11.3. See the linked exact
results and [agent visual review](../architecture/usability-review-m114.md);
agent walkthroughs are distinct from human usability studies.

The existing eight-window/ASCII/path/provider limits remain explicit. No universal
hardware support, physical GPU 3D, arbitrary fonts/photos, multi-monitor desktop,
selected-partition installation, dual boot or general Windows compatibility is
claimed. MS-DOS/Windows expansion remains separate; the established original
7-Zip MSI/console profile is not a general Windows Installer implementation.

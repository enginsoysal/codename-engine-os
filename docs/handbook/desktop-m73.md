# Your Engine OS M7.3 desktop

[M7.3 downloads and exact qualification](../releases/m73-v0.7.3.md).

Files opens automatically after installation and when the installed disk
starts. The Home folder and its contents are saved on disk. Choose Documents,
Desktop, Downloads or Pictures in the sidebar. Click a folder to enter it.
Back, Forward and Up navigate; the lower arrow buttons page through a long
list. The location line shows your current path.

Choose New folder, type a name, and choose Create folder or press Enter. Cancel
or Escape keeps the folder unchanged. Delete asks before removing an item;
folders must be empty. There is no trash/recycle-bin recovery in this version.
System drive exposes the installed native volume. Files protects System and
other locations outside your Home from graphical writes. Other partitions are
not automatically mounted; this is not yet a general removable-drive browser.

Appearance opens Settings. Choose Mint, Lavender or Amber, light or dark
windows, and a display size. Auto is the recommended initial setting. Explicit
100%, 150% and 200% choices are offered where enough room remains. If a choice
is refused, your previous size remains usable. Save preferences records it on
disk; an unsuitable saved size falls back to Auto on a smaller framebuffer.

The desktop does not depend on Calculator. Its optional installation/removal
control stays in Settings. This release prioritizes the installer, folder
desktop and readable UI rather than adding more applications. Existing native
Editor functions remain available for personal text files. Advanced Terminal
and Details remain optional diagnostic tools.

For a useful first test: install, open the desktop, enter Documents, create a
folder with your own name, change the accent/display size, save preferences,
then power off and boot from the SATA disk with only the CD disconnected.
Confirm the folder and display choice remain.

# M4 - storage, discovery and input

**Complete within the documented bounded native virtual-device scope.** Original AHCI storage, writable ext2/VFS, USB boot keyboard/mouse and PS/2/COM1 diagnostic input. The fresh linked acceptance report is required evidence; this statement alone is insufficient.

See the [implementation, usage and exact limits](m4-contract.md), [acceptance report](../../evidence/M4/acceptance-results.json) and [evidence](../../evidence/M4/README.md). M4 qualifies named virtual devices and a restricted filesystem profile; it does not include the M5 installer, M6 desktop or Windows application support.

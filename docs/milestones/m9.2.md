# M9.2 — automatic writable storage and reachable off-screen windows

Status: **delivered within M92-STORAGE-VM-v1; the broader hardware program and explicitly recorded QEMU failures remain open.** The owner requires working IDE/SATA/SCSI installation without choosing a controller to accommodate the installer. Hardware work takes priority over additional Windows application profiles.

## Required user tasks

- Discover each implemented controller automatically, verify actual data transfer and expose writable capability independently of the bus name.
- Select a disk through the ordinary graphical installer, safely review/erase existing partitions where requested, install, restart and boot the same disk with the ISO disconnected.
- Create and persist real folders/documents, format/manage another supported test disk, exercise original Windows archive tasks and independently inspect the resulting disk bytes.
- Keep all shipped VM devices enabled. Observe BIOS/UEFI behavior separately; firmware support and native controller support are distinct.
- Allow Files windows to overlap the side and bottom edges, with a visible title-bar grip for recovery. Clip drawing safely and preserve correct window contents on return.

## Qualified controller matrix and boundaries

ATA PIO IDE, existing SATA/AHCI, NVMe, modern VirtIO Block, LSI Logic parallel/MPI, LSI SAS/MPI, VMware PVSCSI and BusLogic mailbox SCSI have native implementations. The release table records thirteen actual VMware controller/firmware lifecycle profiles plus the exact starter. VirtIO has separate QEMU original-app write/flush proof; it is not a universal boot claim. Do not extrapolate to every physical HBA, RAID controller, USB bridge or SCSI implementation.

The installed layout still uses 512-byte logical sectors and its documented capacity bounds. Drivers may discover other geometries without authorizing installation onto them. The broader M9 program includes additional storage transports, GPU modes/acceleration, network/audio devices, reconnect/hotplug and separately qualified physical/ARM profiles. It remains in progress.

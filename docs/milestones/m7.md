# M7 — real Engine OS desktop

Status: **complete within M7-VM-v1**, 7 November 2026. [Exact acceptance](../../evidence/M7/acceptance-results.json) passes all 26 gates and verifies 146 unchanged prior accepted proofs. M6 and earlier accepted artifacts/evidence remain unchanged. The product is Engine OS. [Owner contract](../roadmap/milestones.md).

## Delivered behavior and choices

The installed M7 disk enters an original native CPU-rendered desktop after the graphical Next/Back/Install/Finish wizard. Eight generation-bound window slots support stacking, focus, movement, resizing, minimization, close and reuse. Damage-driven rendering avoids a backing framebuffer per window and stops painting at idle. Keyboard routes expose actual button focus, with F10, Tab/Shift+Tab, Enter and Alt+Tab alongside mouse input.

Files supports current-directory creation, folder navigation and explicit safe deletion confirmation. Text Editor supports real persistent documents, named Save as, clipboard and dirty/conflict protection. Settings retains appearance and independently removes/reinstalls the actual optional Calculator executable. Advanced Terminal is an optional native window for the original bounded diagnostic/file commands. Normal setup and document tasks require no terminal syntax. These are automated user-task checks, not a human usability study.

Editor and Calculator are actual separately installed original ELF programs executing in private CPL3 address spaces. Immutable code is shared; private pages, guarded stacks and checked mailboxes are bounded and reaped. Native UD2, CPU timeout, forbidden kernel/code writes and malformed output are contained while another Editor still saves. The compositor, Files, Settings, network and Terminal remain trusted supervisor services. This event-worker ABI is narrower than a general app scheduler. [Boundary, alternatives and limits](../architecture/desktop-m7.md).

An original Intel 8254x/82574 Ethernet driver plus DHCP/ARP/DNS/TCP/HTTP connects the native Downloads window to actual public HTTPS files. TLS 1.2 uses unchanged MIT BearSSL 0.6, explicit RDRAND entropy, valid UTC and pinned MPL-2.0 Mozilla/curl roots. Original bounded transport and 4-KiB streamed COW storage avoid whole-download managed buffers. Certificate errors, downgrade, cancellation, cable loss/recovery and invalid RTC are separate gates. The larger test independently checks the original public 7-Zip installer bytes after restart, without executing it. [Network choices and limitations](../architecture/network-m7.md).

Schema-2 profiles affect actual branding, accent, dark/light defaults, wallpaper, tagline, data and Calculator installation. The independently booted Night image demonstrates those choices without removing the required Editor/base. Unknown hooks and core-removal fields are refused. [Distribution guide](../handbook/distributions.md).

## Acceptance matrix

The final [acceptance collector](../../tests/m7/verify.py) requires four complete gate groups, exact committed source bytes and exact standard/Night artifact digests. A build or attractive screenshot alone cannot close M7.

| Group | Required proof |
|---|---|
| Host, 9 gates | Original C window geometry/state, media overlap/bounds, packet parsing/mutations, TCP, actual TLS policy, calendar, HTTP framing, streamed storage interruptions, strict distro profiles |
| Native, 13 gates | Everyday file/terminal tasks, 64/128-MiB pressure/idle recovery, saved/reopened documents, actual app isolation/removal, e1000/e1000e packets/link recovery, positive/negative HTTPS, original larger binary download, BIOS/UEFI optical/raw-USB installation and detached desktop |
| Custom, 2 gates | Native Night defaults/optional app behavior/restart, distinct kernel update/rollback and deliberately damaged BIOS repair with complete data-partition digest preservation |
| VMware, 2 gates | Workstation 26.0.1 BIOS/UEFI on a new 20-GiB SATA disk, actual framebuffer/PS2 Editor input, real e1000e MSI/NAT HTTPS and detached restart; existing VM inventory unchanged |

CPU/RAM evidence separates managed allocator state, whole-boot peak, static kernel span and visible framebuffer. A second Editor uses 40,960 private bytes with shared immutable code. Real allocation refusal leaves an already open Editor usable; restoring the quota and closing apps returns to baseline. Idle CPUs halt and painting stops. Configured VM RAM is not kernel consumption.

## Reproduce without changing older releases

```powershell
python tools/build/m7.py
python tools/build/m7.py --revision night --profile distros/engineos-night.json
python tests/m7/qualify.py host
python tests/m7/qualify.py native
python tests/m7/qualify.py custom
python tests/m7/qualify.py vmware
```

Finish building both images before qualification. Do not edit the captured harness/source or rebuild standard media during a gate group. Run VMware gates serially; the runner does this automatically. Tests use owned disposable images/headless guests, not host desktop automation. Acceptance additionally requires `python tests/m7/verify.py --source-commit COMMIT`, where COMMIT contains the exact build inputs. Installed ELF/map addresses differ from the live embedded-payload kernel; native debugger tests use the matching installed map.

[VMware tutorial](../handbook/install-m7.md), [desktop controls](../handbook/desktop-m7.md), [release limits](../releases/m7-v0.7.0.md). Qualification is M7-VM-v1, not universal hardware support, physical-machine certification or factory Secure Boot. Original MS-DOS and Windows 1.x–11 compatibility remains M8, not a claim derived from downloading a Windows executable.

## Retained development failures

Earlier trusted-callback-only prototypes did not satisfy app isolation. Earlier network/VMware profiles lacked entropy or supported IRQ routing; unsupported devices were refused/quarantined. Harness corrections include choosing the installed rather than live map, waiting for complete serial markers, matching revised Start-menu navigation, acknowledging typed prefixes and delaying an interruption fixture so a transfer cannot finish before cancellation. Honest failed reports and explanations remain under `evidence/M7/history`. None is counted as a passed final gate.

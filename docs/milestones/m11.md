# M11 — familiar installation and desktop experience

Owner-authorized on 11 November 2026. Execute **M11.0 → M11.1 → M11.2 →
M11.3 → M11.4 → M11.5 → M11.6**, in that order. Each stage closes its own
checks, updates English documentation, pushes to GitHub and verifies the public
website before implementation of the next stage begins. Later hardware/network
phases are deferred until this sequence finishes. This supersedes the previous
next-work priority, not accepted M10 qualification.

The reference is familiar Windows mouse, Explorer, Start and Setup behavior,
implemented in original Engacer OS code and artwork. The milestone is a concrete
shell/installation contract, not full Windows API compatibility. Existing original
7-Zip and device support must retain regression evidence. The complete M11
qualification remains M11.6. The owner's subsequent M11.4 clarification requires
a visible, separately scoped GitHub release and matching test media after each
remaining stage, with complete website/manual/download updates before the next
stage. M10 remains an immutable earlier delivery; its broad controller matrix
must not be attributed to an untested M11 stage artifact.

## Ordered stages

| Stage | Delivery | Required closing evidence |
|---|---|---|
| M11.0 | Interaction/visual/installation contract and original screen designs | Reviewed specifications, four clearly labeled concept screens, resource/safety bounds, stage criteria and public publication; no new runtime claim |
| M11.1 | Selection, primary/secondary release, double-click, focus, keyboard and drag threshold | Production input state-machine checks and actual native guest selection/open/cancel/right-click/keyboard tasks; single click must not open a file/icon |
| M11.2 | Files, context operations, clipboard, rename, recycle/restore, views and drag/drop | Native create/copy/cut/paste/rename/recycle/restore tasks; independent stored-byte inspection, collision/protection/error paths and persistence |
| M11.3 | Searchable Start, categories, pins and taskbar | Actual launch/search/category/pin/reorder/remove tasks; saved preferences and no stale launches after optional app removal |
| M11.4 | Window commands, snapping, switcher, visual system and personalization | Ordinary/150%/real 4K captures, clipping/focus/resize/snap/Alt+Tab, persistence, memory/idle/motion observations |
| M11.5 | Full guided setup and first installed desktop | Real disk/partition choices, guarded format, retained Back/Next choices, actual copy/readback/restart; same VM and disk-only boots, failure/recovery tasks |
| M11.6 | Full regression, final publication and exact VMware media | Frozen-source/artifact acceptance, enabled-device VMware controller/firmware matrix, original-app/device regressions, docs/site/download readback and final ISO/ZIP hashes |

An attractive concept or a compiled binary cannot close a runtime stage. A known
failed test must stay visible until fixed or explicitly outside the previously
agreed scope; do not silently remove required behavior to finish sooner.

## Completion journey

Install on a disposable supported disk → Restart → actual installed desktop →
single-click select → double-click open → copy/move a file → rename → recycle →
restore → start/search an optional app → customize appearance/pins/categories →
restart → verify saved files and preferences. Repeat with keyboard routes, USB
round trips and both retained/removed ISO. Test ordinary and 4K native buffers.

## Publication and artifact isolation

Keep `build/m11*`, `dist/EngacerOS-M11*`, `tests/m11` and `evidence/M11` separate
from accepted M10 outputs and proof. Intermediate stage artifacts must identify
their partial scope. Final M11 media must not be rebuilt after qualification.
Preserve original release identities and do not reuse M10 hashes for M11.

Website progress must distinguish a completed design stage from a running feature
and the tested downloadable release. Close each publication with a successful
Actions content readback and fresh anonymous article/homepage check. A content
sync alone is not proof of a native homepage edit.

# M7.3 — native visual quality and HiDPI

Status: in progress. M7.2 remains the latest accepted release until exact M7.3
runtime and publication checks pass.

The goal is a readable, attractive installer and real folder desktop, with
ordinary users guided through choices rather than terminal commands. The owner
requires a review of clarity, convenience, friendliness, graphical quality and
readability for each ordinary step, confirmation and error.

Implemented candidate work includes native antialiased Inter text, semantic
typography, measured wrapping and fitting, consistent rounded controls,
installer and disk/recovery layouts, scaled input and cursor, and saved desktop
display sizing. A separate 0.7.3 distribution profile preserves the older
release inputs. This does not add foreign application compatibility.

Acceptance requires native installation and persistent folder tasks, actual
3840×2160 framebuffer evidence, suitable lower-resolution layouts, display
setting persistence and refusal of unsuitable sizing, detached VMware boot,
disk safety checks, bounded resources and input-idle behavior. The full OFL
font notice must travel with distributed binaries and the installed system.

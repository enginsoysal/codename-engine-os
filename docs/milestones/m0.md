The baseline has 51 technical checks: 11 toolchain/layout/Windows basics, 30 C contract checks, eight further host references and two firmware fixtures. Aggregate tests also cover 160 truncated boot lengths, 24 truncated request lengths and 1000 deterministic bit mutations. Run `python tests/m0/verify.py` on the pinned Windows host.

## Handoff boundaries

M0's EFI fixture writes a marker and exits; it never transferred to an own kernel. M1 subsequently proved that handoff. M2 subsequently added limited native user processes. Guest TLS/SEH, preemption/races, Linux/Mach and physical support retain their own gates. The historical claim is not expanded merely because current code has advanced.

Unavailable physical test hardware did not block virtual development. Do not use the host disk as a test target. New findings can amend contracts with explicit rationale and regression evidence. [Original M1 handoff](m1-handoff.md).
